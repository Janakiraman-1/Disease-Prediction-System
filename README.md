# Disease-Prediction-System
Machine Learning project for predicting diseases using healthcare datasets and classification algorithms.

📌 Overview

The Disease Prediction System is a Machine Learning project used to predict diseases using patient healthcare data.
This project helps in analyzing medical attributes and predicting whether a disease is detected or not using classification algorithms.

The project is developed using Python and Jupyter Notebook with different Machine Learning libraries for training and evaluation.

🚀 Features
Data preprocessing and cleaning
Disease prediction using Machine Learning
Model training and testing
Accuracy and performance evaluation
Save trained model using Joblib
Simple and easy workflow in Jupyter Notebook
🛠️ Technologies Used
Python 3.x
NumPy
Pandas
Scikit-learn
Matplotlib
Seaborn
Joblib
Jupyter Notebook
